Added a warnings baseline mechanism for gradually converging an existing set of warnings. Captured warnings can be registered in a baseline file keyed by test node id, warning category, code location and message (``--warnings-baseline`` together with ``--warnings-baseline-update`` or ``--warnings-baseline-merge``). On later runs, warnings not present in the baseline are reported (``warnings_baseline_on_new = warn``) or fail the run with the new ``pytest.ExitCode.WARNINGS_BASELINE_ERROR`` exit code (``7``, ``warnings_baseline_on_new = fail``), while baseline entries that no longer occur are listed as write-off candidates. Baseline files carry a schema version and generation-environment markers and are written atomically; when no baseline is configured, warnings capture, filtering and summary behaviour is unchanged.
